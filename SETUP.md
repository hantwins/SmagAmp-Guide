# SmagAmp Setup Guide

After inviting SmagAmp to your server, run:

`/setup`

The setup wizard walks you through:

1. Channels — welcome, goodbye, level-up, mod-logs, tickets, staff chat
2. Roles — admin roles, staff role, default member role, booster role
3. Anti-spam consequences
4. AI moderation settings
5. Vote settings
6. Server rules

## Permissions

Make sure SmagAmp’s role is above the roles it needs to manage.

SmagAmp may need:

- Manage Channels
- Manage Roles
- Manage Messages
- Kick Members
- Ban Members
- Moderate Members
- Read Messages
- Send Messages
- Embed Links
- Attach Files
- View Audit Log
