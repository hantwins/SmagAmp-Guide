# SmagAmp Privacy Policy

Last updated: May 2026

SmagAmp is a Discord bot that helps servers with moderation, anti-spam, leveling, welcome cards, tickets, polls, giveaways, logging, stats, auto-role, and AI moderation.

## Data SmagAmp May Process

Depending on enabled features, SmagAmp may process:

- Server IDs
- Channel IDs
- Role IDs
- User IDs
- Message content for moderation, anti-spam, logging, and AI moderation
- Warning records
- Ticket records
- Poll and giveaway data
- XP and leveling data
- Server configuration settings

## AI Moderation

If AI moderation is enabled, SmagAmp may send message content and related context to an AI provider to check whether the message violates the server’s custom rules.

SmagAmp’s AI moderation is designed to enforce only the rules set by the server using `/setrules`.

## Message Logging

If audit logging is enabled, SmagAmp may log deleted or edited message content to the server’s configured mod-log channel.

## Data Sharing

SmagAmp does not sell user data.

Message content may be sent to an AI provider only when AI moderation is enabled and only for moderation purposes.

## Data Deletion

Server owners may request deletion of their server’s stored SmagAmp data by contacting the support server.
